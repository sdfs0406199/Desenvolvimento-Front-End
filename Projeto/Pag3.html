1. Como Funciona a Internet?

A internet é uma rede global de computadores interconectados. Quando você digita um endereço no seu navegador, ele envia uma solicitação usando o protocolo HTTP ou HTTPS.

Os principais componentes que fazem a web funcionar são:

  • Navegador (Cliente): Interpreta o código HTML.
  • Servidor: Computador que guarda o site e o envia quando solicitado.
  • DNS: Encontra o endereço IP do site.

Para aprender mais, acesse o site W3C (World Wide Web Consortium).
